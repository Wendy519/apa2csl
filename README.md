Simple and imperfect way to convert APA style references to CSL JSON for importing into reference managment software like Zotero. 
Just copy the references from a bibliography and convert.
It doesn't handle all media types, just articles and books for now, but everything else will import as one of those. 
For videos or other types, you'll need to make manual changes once it's in your software. Not ideal, but better than inputting everything from scratch.
